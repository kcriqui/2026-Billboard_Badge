\# Simple image display and Larson scanner app



from Ben Combee

* https://combee.net
* https://bsky.app/profile/unwiredben.combee.net



to install



```

mpremote cp kitt.py :apps

mpremote cp kitt\_b\_w\_r.png :data/graphics

```



then restart badge and select the Kitt app.  Modify the delay to make scanning faster or slower.
