# Want to Share With the Class?

The firmware for the 2026 Supercon badge is designed to make it easy to add new applications -- now we just need somebody to write them.

If you've created an application or demo that you'd like to share with the wider Hackaday community, make a subdirectory here and send us a Pull Request. The best apps may even get baked into the firmware at some point, so if there's some specific way you'd like to be credited make sure to add that to the code.
